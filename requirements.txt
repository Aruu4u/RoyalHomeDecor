# =========================================================
#  Royal Home Decor - Python dependencies
# =========================================================
#
#  Everything the backend API needs, for the whole project in
#  one file.
#
#      python -m venv venv
#      venv\Scripts\activate          (Windows)
#      source venv/bin/activate       (macOS / Linux)
#      pip install -r requirements.txt
#
#  Requires Python 3.11 or newer. Developed and tested on
#  3.11.9.
#
#  The frontend is a separate Node project and is not covered
#  here. Install it with `npm install` inside
#  luxury-furniture-frontend (Node 20+; built on Node 24.11.1).
#
#  ---------------------------------------------------------
#  Why the versions are pinned
#  ---------------------------------------------------------
#
#  These are the exact versions the test suite passes against.
#  An unpinned list installs whatever is newest on the day, so
#  a fresh clone can break through no change of your own, and
#  a bug that only appears on the server becomes very hard to
#  reproduce. Pinning also removes the window where a
#  compromised release of a dependency would be picked up
#  automatically.
#
#  To move up a version deliberately, change it here and run
#  the test suite.
