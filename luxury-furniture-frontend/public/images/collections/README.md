# Collection card images

One portrait image per collection, named after that collection's slug.

Expected filenames for your current collections:

```
arched-brass-mirror.jpg
mirrors.jpg
dining-tables.jpg
wall-decor.jpg
tables.jpg
```

Recommended size: **900 × 1200** (portrait, 3:4). These sit in the moving
rail on the home page, and also become the banner background on that
collection's own page.

Any file you don't add simply keeps using the image already set on the
collection in the admin area.

If you add a new collection later, add its slug to
`src/config/siteImages.ts` and drop a matching file here.
